# Orbit — Infinite Canvas v1.0

A browser-based infinite dot-grid notebook and drawing workspace.

Start drawing or writing. Changes are saved locally in that browser using IndexedDB.

For Android/WebCode, import all three files into one project and keep their names and relative paths unchanged.

## Included
- Infinite pan/zoom canvas with dot, square, lined, and blank backgrounds
- Pen, highlighter, eraser, text, rectangle, ellipse, line, arrow, selection, and hand tools
- Color palette, custom color, brush size, opacity
- Multiple notebooks and pages
- Local autosave, undo/redo, keyboard shortcuts
- Image insertion
- PNG export, browser print-to-PDF, JSON backup and restore
- Light/dark theme and responsive mobile layout

## Notes
- This is a local-first v1.0: data stays in the browser on the device where it was created.
- PDF export uses the browser's Print dialog. Choose “Save as PDF”.
- Cloud accounts and cross-device sync are not included.
- For best compatibility, use a recent Chrome, Edge, or Firefox browser.
